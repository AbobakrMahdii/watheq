## 🎯 نظرة عامة على المشروع

### وصف المشروع
**Watheq** هو نظام شامل لإدارة وتوثيق المستندات الرسمية باستخدام تقنيات متقدمة:
- **Backend:** FastAPI (Python)
- **Frontend:** Next.js Dashboard (TypeScript/React)
- **Blockchain:** Hyperledger Fabric
- **Storage:** IPFS (InterPlanetary File System)
- **AI/ML:** نماذج للتحقق من التوقيعات، الأختام، OCR، والتعرف على الوجوه

### المكونات الرئيسية
1. **API Backend** (`api/`) - FastAPI REST API
2. **Admin Dashboard** (`dashboard/`) - Next.js Admin Panel
3. **Blockchain Layer** (`ledger/`) - Hyperledger Fabric Chaincode
4. **IPFS Service** (`ledger/ipfs_service.py`) - تخزين الملفات
5. **AI Services** (`ai/`) - نماذج ML للتحقق من المستندات

   ```python

       "http://localhost:3000",
       "https://yourdomain.com"

   ```

2. **SECRET_KEY مكشوف في الكود**
   ```python
   # api/config.py:1
   SECRET_KEY = "a_secure_random_generated_key_1234567890!@#$%^&*()_+"
   ```
   **الحل:** استخدام Environment Variables
   ```python
   SECRET_KEY = os.getenv("SECRET_KEY")
   if not SECRET_KEY:
       raise ValueError("SECRET_KEY must be set")
   ```

3. **API Key مكشوف في .env**
   ```bash
   # .env
   GOOGLE_VISION_API_KEY=AIzaSyBowuRTs9j25JIElBgtjBehuptsspeJcVQ
   ```
   **الحل:** إضافة `.env` إلى `.gitignore` والتأكد من عدم رفعه

4. **Document Verification بدون Authentication**

#### أ. إنشاء جدول Audit Logs

```sql
CREATE TABLE IF NOT EXISTS audit_logs (
    id INT AUTO_INCREMENT PRIMARY KEY,
    user_id INT NOT NULL,
```

#### ب. إنشاء Middleware للـ Audit Logging
```python
# api/middleware/audit_middleware.py
from fastapi import Request
from starlette.middleware.base import BaseHTTPMiddleware
from api.database import database

class AuditLogMiddleware(BaseHTTPMiddleware):
    async def dispatch(self, request: Request, call_next):
        # Get user from token if available
        user = None
        if "authorization" in request.headers:
            try:
                token = request.headers["authorization"].replace("Bearer ", "")
                user = decode_token(token)
            except:
                pass
        
        # Log the request
        if user and request.url.path.startswith("/api/v1"):
            await log_audit_event(
                user_id=user.get("sub"),
                user_email=user.get("email"),
                action=request.method + " " + request.url.path,
                ip_address=request.client.host,
                user_agent=request.headers.get("user-agent"),
            )
        
        response = await call_next(request)
        return response
```

#### ج. إنشاء Router لعرض Audit Logs
```python
# api/routers/audit_router.py
from fastapi import APIRouter, Depends, Query
from api.security import get_current_admin
from api.database import database

router = APIRouter(prefix="/api/v1/audit", tags=["Audit"])

@router.get("/logs")
async def get_audit_logs(
    admin=Depends(get_current_admin),
    skip: int = Query(0, ge=0),
    limit: int = Query(100, ge=1, le=1000),
    user_id: int = Query(None),
    action: str = Query(None),
):
    query = "SELECT * FROM audit_logs WHERE 1=1"
    params = {}
    
    if user_id:
        query += " AND user_id = :user_id"
        params["user_id"] = user_id
    
    if action:
        query += " AND action = :action"
        params["action"] = action
    
    query += " ORDER BY created_at DESC LIMIT :limit OFFSET :skip"
    params["limit"] = limit
    params["skip"] = skip
    
    rows = await database.fetch_all(query, values=params)
    return [dict(row) for row in rows]
```

```go
func (s *SmartContract) GetAllDocuments(ctx contractapi.TransactionContextInterface) ([]*Document, error) {
    iterator, err := ctx.GetStub().GetStateByRange("", "")
    if err != nil {
        return nil, err
    }
    defer iterator.Close()

    var documents []*Document
    for iterator.HasNext() {
        response, err := iterator.Next()
        if err != nil {
            return nil, err
        }

        var doc Document
        err = json.Unmarshal(response.Value, &doc)
        if err != nil {
            return nil, err
        }
        documents = append(documents, &doc)
    }

    return documents, nil
}
```
