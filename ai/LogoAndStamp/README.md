المميزات الرئيسية

تحليل متعدد الإشارات: يجمع بين SSIM و ORB و ResNet50 وشبكات Siamese لاتخاذ قرار محافظ ودقيق.

استخراج متين لمناطق الاهتمام (ROI): يستخدم آلية Jitter Search لتحديد موقع الختم حتى مع وجود انحرافات بسيطة في موضعه.

مستويات متعددة لاكتشاف التزوير: قادر على اكتشاف:

التزوير الواضح (المستوى الأول)

التزوير الدقيق (المستوى الثاني)

التزوير شبه الحقيقي (المستوى الثالث)

قابلية التفسير: يقدّم أسبابًا تفصيلية لكل قرار يتم اتخاذه (أصلي، مشبوه، أو مزوّر).

التقنيات المستخدمة

Python 3.10+

OpenCV: لمعالجة الصور والمطابقة الكلاسيكية (SSIM و ORB).

PyTorch: لتشغيل نموذج ResNet50 وشبكة Siamese لقياس التشابه.

NumPy و YAML: لإدارة البيانات وملفات الإعدادات.

التثبيت

استنساخ المستودع (Clone repository)

استخدم بيئة المشروع الموحّدة الموجودة في الجذر (لا تنشئ venv جديد هنا):

..\..\.venv\Scripts\activate


تثبيت المتطلبات:

pip install -r requirements.txt

طريقة الاستخدام

لتشغيل التحقق الموحد على مستند واحد:

python main_unified.py --input path/to/document.jpg

بنية النظام

يعتمد نظام وثيق على استراتيجية تحقق مكونة من أربع طبقات:

الطبقة الهيكلية (SSIM): لتحليل السلامة الهندسية والبنيوية.

طبقة الخصائص (ORB): لمطابقة النقاط المميزة والتحقق من هوية العنصر.

الطبقة العميقة (ResNet50): لاكتشاف أنماط التزوير المتعلمة والتشوهات.

طبقة التشابه (Siamese): لحساب درجة التشابه العميق مع العينات المرجعية.
