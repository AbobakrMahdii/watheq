┌─────────────────────────────────────────────────────────────┐
│ الخطوة 1: التحقق من أن Backend يعمل                        │
└─────────────────────────────────────────────────────────────┘

1. افتح المتصفح واذهب إلى:
   http://localhost:8001/api/v1/docs
   
   ✅ إذا ظهرت صفحة Swagger UI → Backend يعمل
   ❌ إذا لم تفتح → Backend لا يعمل (انظر الخطوة 2)

┌─────────────────────────────────────────────────────────────┐
│ الخطوة 2: تشغيل Backend API                                │
└─────────────────────────────────────────────────────────────┘

إذا كان Backend لا يعمل:

1. افتح نافذة CMD جديدة

2. شغّل Backend:
   cd "c:\Users\sadeq\Desktop\المشروع_2\‏‏watheq - نسخة"
   start_backend.bat

   أو يدوياً:
   cd api
   python -m venv venv
   venv\Scripts\activate
   pip install -r requirements.txt
   python -m api.main

3. انتظر حتى ترى رسالة:
   "Uvicorn running on http://0.0.0.0:8001"

4. الآن جرب الدخول إلى Dashboard مرة أخرى

┌─────────────────────────────────────────────────────────────┐
│ الخطوة 3: التحقق من MySQL                                 │
└─────────────────────────────────────────────────────────────┘

إذا كان Backend لا يبدأ، قد تكون المشكلة في MySQL:

1. تأكد من أن MySQL يعمل:
   - افتح Services (services.msc)
   - ابحث عن MySQL
   - تأكد من أنه "Running"

2. أو شغّل MySQL يدوياً:
   - ابحث عن MySQL في Start Menu
   - أو شغّل: net start MySQL

┌─────────────────────────────────────────────────────────────┐
│ الخطوة 4: التحقق من المنافذ (Ports)                       │
└─────────────────────────────────────────────────────────────┘

1. افتح Command Prompt كـ Administrator

2. تحقق من المنفذ 8001:
   netstat -ano | findstr :8001

3. إذا كان المنفذ مستخدم:
   - أغلق التطبيق الذي يستخدمه
   - أو غيّر المنفذ في api/main.py

┌─────────────────────────────────────────────────────────────┐
│ الخطوة 5: التحقق من Firewall                              │
└─────────────────────────────────────────────────────────────┘

1. افتح Windows Firewall

2. تأكد من أن Python مسموح له بالاتصال

3. أو أضف قاعدة:
   - Allow inbound connection on port 8001
